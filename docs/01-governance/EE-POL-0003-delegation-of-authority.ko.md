# 전결 규정

> 본 문서는 EE-POL-0003 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 목적

본 규정은 회사의 각 조직 단위가 스스로의 권한으로 승인할 수 있는 결정과 더 위로 올리는 결정을 정한다.

## 2. 적용 범위

1. 본 규정은 저장소가 기록하는 모든 결정에 적용된다. 변경 요청, 문서, 머지, 릴리스, 배포, 아키텍처 결정, 품의서, 인가된 예외이다.
2. 조직 단위와 그 보고 대상과 담당자는 조직도(EE-ORG-0001)를 따른다.

## 3. 정의

| 용어 | 뜻 |
|---|---|
| 전결 | 조직 단위가 결정을 더 위로 올리지 않고 회사의 이름으로 승인하는 권한 |
| 결재 라인 | 품의서가 왼쪽에서 오른쪽으로 거치는 담당자들(EE-TPL-0005) |

## 4. 전결

1. 결정은 표가 정한 조직 단위의 담당자가, 또는 EE-ORG-0001 에서 그보다 위에 있는 조직 단위의 담당자가 승인한다.

| 결정 | 승인 | 기록하는 곳 |
|---|---|---|
| 변경 요청을 승인 상태로 등록 | 변경 자문 위원회 | 결재 절과 상태(EE-POL-0004 §4) |
| `develop` 또는 `main` 으로의 머지 | 변경 자문 위원회 | 머지의 `Approved-by` trailer(EE-POL-0004 §7) |
| 통제 문서 또는 그 개정 | 그 문서를 소유한 조직 단위 | 결재 절과 상태(EE-POL-0001 §10) |
| 아키텍처 결정 기록 | 아키텍처 검토 위원회 | 그 상태(EE-TPL-0004) |
| 릴리스의 배포 | 릴리스 엔지니어링 | `production` 환경(EE-STD-0008 §6) |
| 금지 API 목록에 대한 인가된 예외 | 규정 준수 엔지니어링 | EE-STD-0003 §6 의 대장 |
| 품의서 | 결재 라인의 모든 담당자 | 그 결재 라인(EE-TPL-0005) |
| 업무에 에이전트를 투입 | 인사팀 | 에이전트를 투입하는 세션 |
| 표에 없는 모든 것 | 이사회 | — |

2. 기록상 결재권자가 모든 조직 단위를 맡는다(EE-ORG-0001 §4).
   따라서 표의 모든 결정은 그 결정을 기록하는 문서가 이미 요구하는 대로 기록상 결재권자가 승인하며, 표는 각 승인이 어느 조직 단위의 이름으로 이루어지는지를 정한다.
3. 에이전트는 조직 단위를 맡지 않으며 아무것도 승인하지 아니한다(EE-POL-0006 §4).
4. 사람이 한 명뿐인 회사에서는 결정을 요청하는 사람과 승인하는 사람이 같다.
   그러한 승인은 유효하며 다른 승인과 똑같이 기록한다. `production` 환경이 한 명뿐인 검토자에게 그 사람이 시작한 배포를 승인하도록 허용하는 이유가 이것이다.

## 5. 시행

본 규정은 자체 checkpatch 규칙을 두지 아니한다.
각 승인은 표가 인용한 문서가 요구하는 대로 기록되며, 그 문서에서 검사된다.
