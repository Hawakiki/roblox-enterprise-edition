# 헌장, 문서 체계 정책 및 양식 제정

> 본 문서는 CR-0003 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 요약

CR-0001 은 문서 규칙을 강제하는 장치를 만들었다.
본 변경 요청은 그 규칙을 문서로 제정하여, 장치가 무엇을 근거로 강제하는지를 마련한다.

## 2. 배경

현재 문서 스키마는 `scripts/lib/Schema.luau` 에 코드로만 존재한다.
코드는 통제 문서가 아니며, 통제 문서에 쓰이지 않은 규칙은 규칙이 아니다.
따라서 본 변경이 승인되기 전까지 회사는 존재하지 않는 규칙을 강제하고 있는 셈이다.

## 3. 범위

- 문서 위계의 최상위인 헌장
- 문서 체계 정책: 문서 종류, 식별자, frontmatter, 버전, 위계, 참조, 문서 대장
- 이중 언어 정책: 정본과 번역본 요건
- 양식 7종: 통제 문서, 변경 요청서, 의견 요청서(RFC), 아키텍처 결정 기록(ADR), 품의서, 경위서, 회의록
- 마지막 세 양식을 실제로 쓸 수 있도록 신설하는 기록 종류 3종: 품의서, 경위서, 회의록
- checkpatch 신규 규칙 `UNDOCUMENTED_RULE`: 규칙의 근거 문서가 존재하면, 그 문서가 해당 규칙을 인용해야 한다.

### 범위 관련 비고

본 단계의 원래 계획은 문서 체계 정책과 양식뿐이었다.
문서 체계 정책은 존재하지 않는 상위 문서를 인용할 수 없고 번역 규칙 없이는 완결될 수 없으므로, 헌장과 이중 언어 정책을 앞당겨 포함한다.

## 4. 영향도 평가

| 영역 | 영향 |
|---|---|
| 출력 전달 | 없음. |

| 도구 | 앞으로 모든 규칙은 문서화되어야만 배포할 수 있다. |
