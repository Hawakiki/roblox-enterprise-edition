# EnterpriseEdition 1.2.0 릴리스

> 본 문서는 CR-0024 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 요약

본 변경 요청은 EnterpriseEdition 1.2.0 을 릴리스한다.
회사의 첫 코드 리뷰와 그 정정 일곱 건(CR-0018), 회사의 첫 아키텍처 결정 기록과 기록이 낡았을 때 알려 주는 테스트(CR-0019, CR-0020, CR-0023), 회사의 조직도와 전결 규정(CR-0021), 그리고 전역 난수 생성기 금지(CR-0022)를 담는다.
다음 릴리스는 옛 타입 솔버를 없앨 예정이며, 그렇게 되면 2.0.0 이 된다.

## 2. 배경

1.1.0 이후 CR-0018 부터 CR-0023 까지가 승인되어 `develop` 에 들어왔다.
이들은 로블록스 코드의 결함 일곱 건을 정정하고, 그 코드를 Lune 아래에서 실행하는 하네스를 저장소에 들이고, 예약된 번호에 정책 하나와 조직도를 작성하고, 결정 기록 두 건을 등록하고, checkpatch 규칙 두 개를 더하고, 표준 세 개를 각각 MINOR 버전으로 개정한다.

이들은 1.1.0 사용자가 기대는 것을 아무것도 바꾸지 않는다(EE-STD-0008 §4.2).
`v1.1.0` 이후 계약 모듈, 서비스 토큰 대장, `default.project.json`, `DataStoreConstants` 는 바뀌지 않았고, 지갑이 데이터 저장소에 남기는 기록의 필드도 같다.
개정된 승인 문서는 모두 MINOR 버전으로 올랐으므로, 없애거나 바꾼 의무는 없다.
따라서 이 릴리스의 번호는 1.2.0 이다(EE-STD-0008 §4.3).

## 3. 범위

- `develop` 에서 딴 `release/1.2.0`(EE-POL-0004 §5)
- push 하지 않는 새 clone 에서의 예행연습: 릴리스를 `main` 에 머지하고 그 머지 커밋에 태그를 달고, 워크플로처럼 태그를 detached 로 체크아웃하여, 모든 검사를 돌리고, 플레이스를 빌드하고, 1.2.0 의 노트를 생성한다.
- 승인 후, 변경 동결이 아닐 때: `release/1.2.0` 을 `--no-ff` 로 `main` 에 머지하고, 그 머지 커밋에 `v1.2.0` 태그를 달고, `release/1.2.0` 을 `develop` 에 다시 머지한다.
- `main`, `develop`, 태그의 push 와 `production` 환경의 배포 승인은 기록상 결재권자에게 맡긴다.
  워크플로가 1.2.0 을 어떻게 배포했는지는 다음 요청이 기록한다.

## 4. 영향도 평가

| 영역 | 영향 |
|---|---|
| `main` | 머지 커밋 하나로 1.1.0 에서 1.2.0 으로 옮겨 간다. |
| 릴리스 | 1.2.0 이 플레이스와 노트와 함께 게시되어 최신 릴리스가 된다. |
| 로블록스 코드 | `develop` 그대로이다. 예행연습에서 결함이 나올 때만 릴리스 브랜치가 이를 바꾼다. |
| 문서 분량 | 변경 요청 하나 |

## 5. 원복 계획

`v1.2.0` 의 GitHub 릴리스를 지우고, `main` 과 `develop` 의 머지 커밋을 되돌린다.
태그는 룰셋이 요구하는 대로 남는다. 정정은 1.2.1 로 릴리스한다(EE-STD-0008 §4.6).

본 요청을 시행 완료로 표시하기 전에, push 하지 않는 새 clone 에서 릴리스를 예행연습하였다.
그곳에서 `release/1.2.0` 을 `main` 에 머지하고 그 머지 커밋에 `v1.2.0` 태그를 달았으며, 워크플로처럼 태그를 detached 로 체크아웃하였다. 그 트리는 `release/1.2.0` 의 트리와 같았다.
로블록스 정의를 새로 내려받은 상태에서 `tools/check.sh` 가 통과하였고, `rojo build` 가 54824 바이트의 플레이스를 빌드하였다.
1.2.0 의 노트는 CR-0018 부터 CR-0024 까지를 담았고, `release/1.1.0` 을 `develop` 에 다시 머지한 커밋이 또 인용하는 CR-0017 은 뺐다.
달력은 2026-11-01T01:09:17Z 에 배포를 허용하였다.
예행연습에서 결함이 나오지 않았으므로, 릴리스 브랜치가 바꾸는 것은 이 기록뿐이다.
