# 첫 실전 배치 지적 사항 정정

> 본 문서는 CR-0009 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 요약

CR-0008 은 신입이 처음으로 시행한 변경 요청이다.
신입의 보고서와 뒤이은 검토에서 온보딩, 도구, 규칙의 결함 일곱 가지가 드러났다.
본 변경 요청은 통제 문서를 하나도 바꾸지 않고 일곱 가지를 모두 정정한다.

## 2. 배경

신입은 코드 첫 줄을 쓰기 전에 규칙 약 1,500줄을 읽고, CR-0008 을 39분 만에 시행하고, 규칙 때문에 시간이 든 곳을 빠짐없이 보고하였다.
이어진 검토에서는 새 규칙 7개를 경계 사례 66개로 시험하였고, 그중 64개를 제대로 처리하였다.

| 지적 | 발견 | 책임 |
|---|---|---|
| `AGENTS.md` 는 `Submitted` 요청을 제출하는 방법은 말하지만, EE-POL-0004 §4 가 요구하는 대로 승인을 기다려야 한다는 것은 말하지 않는다. | 신입 | 온보딩 |
| `tools/check` 는 공용 Roblox 타입 정의를 자신이 실행되는 폴더 옆에서 찾는데, 에이전트 작업 사본에서는 그 폴더가 `.claude/worktrees/` 이다. | 신입 | 도구 |
| 문서 주석은 Moonwave 를 위해 쓰지만, 툴체인에는 Moonwave 처럼 문서 주석을 읽는 도구가 없다. 신입은 도구가 없어 직접 내려받아 실행하려 했고, 샌드박스가 이를 거부하였다. | 신입 | 툴체인 |
| `LAYER_VIOLATION` 은 패턴으로 주석을 지우므로, 문자열이 require 를 숨기거나 가짜 require 를 만들 수 있다. | 신입 | 이 규칙을 쓴 검토자 |
| 모든 규칙이 그 규칙을 보고하는 검사와 멀리 떨어진 목록 하나에 선언되어 있고, 표준이 밝힌 심각도와 checkpatch 가 강제하는 심각도를 대조하는 것이 없다. | 검토 | checkpatch 작성자 |
| checkpatch 는 현재 브랜치를 `git symbolic-ref --short` 로 읽는데, 이 명령은 같은 이름의 태그가 있으면 `heads/<이름>` 을 쓴다. | 기록상 결재권자 | checkpatch 작성자 |
| `PROHIBITED_API` 는 `game["GetService"]` 처럼 대괄호로 이름을 댄 멤버를 놓치고, `COLOR_OUTSIDE_PALETTE` 는 `Color3` 의 별칭을 놓친다. | 검토와 신입 | 신입 |

거버넌스는 여전히 동결되어 있다.
모든 정정은 온보딩, 도구, 코드에서 이루어지며, 모든 표준은 본문과 버전을 그대로 유지한다.

## 3. 범위

- `AGENTS.md`: `Submitted` 요청은 기다리며, `Approved` 요청만 시행한다(EE-POL-0004 §4). CR-0008 중에 밟은 지뢰
- `rokit.toml`: 다른 모든 도구처럼 버전을 고정한 `moonwave-extractor`
- `tools/check`: 어느 작업 사본에서든 주 작업 폴더 옆에서 공용 Roblox 타입 정의를 찾고, `moonwave-extractor` 로 `src/` 아래의 모든 문서 주석을 읽는다.
- checkpatch: `LAYER_VIOLATION` 이 어휘 분석기를 거쳐 require 를 읽는다.
- checkpatch: `PROHIBITED_API` 가 대괄호로 이름을 댄 멤버를 읽고, `COLOR_OUTSIDE_PALETTE` 가 `Color3` 이나 `BrickColor` 의 별칭을 보고한다.
- checkpatch: 현재 브랜치를 `git symbolic-ref -q HEAD` 의 전체 이름으로 읽는다.
- checkpatch: 모든 규칙을 그 규칙을 보고하는 검사 옆에 선언하고, 모든 부속서 A 가 밝힌 심각도를 강제되는 심각도에 대조하는 테스트를 둔다.

## 4. 영향도 평가

| 영역 | 영향 |
|---|---|
| 규칙 | 개수는 그대로이다. 규칙 세 개가 전보다 많은 것을 본다. |
| 통제 문서 | 바뀌는 문서가 없다. |
| 툴체인 | 주석을 읽는 도구가 하나 늘어난다. |
| 신입 | 다음 신입은 승인을 기다린 뒤에 일하며, 도움 없이 타입 정의를 찾는다. |
