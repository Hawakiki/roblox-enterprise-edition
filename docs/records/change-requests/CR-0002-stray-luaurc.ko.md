# 루트에 잘못 들어간 .luaurc 제거

> 본 문서는 CR-0002 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 요약

저장소 루트에 실수로 커밋된 `.luaurc` 를 제거하고, 다시 들어오지 않도록 한다.

## 2. 배경

`lune setup` 은 실행한 폴더에 `@lune` 별칭이 담긴 `.luaurc` 를 만든다.
CR-0001 시행 중 저장소 루트에서 실행되었고, 그 결과물이 검토 없이 `git add -A` 로 `dfe02c9` 에 커밋되었다.
이후 CR-0001 머지와 함께 `develop` 에 반영되었다.

의도한 설정은 이미 `scripts/.luaurc` 에 있으며, checkpatch 가 `rokit.toml` 과 버전이 맞는지 검사한다.
루트 사본은 아무것도 검사하지 않으며, 로블록스 코드가 추가되면 Lune 에서 실행되지 않는 코드에까지 Lune 별칭이 적용된다.

## 3. 범위

- 저장소에서 `/.luaurc` 를 삭제한다.
- `tools/check` 가 `lune setup` 을 실행하며 다시 만들게 되므로, `.gitignore` 에 `/.luaurc` 를 추가한다.

## 4. 영향도 평가

| 영역 | 영향 |
|---|---|
| 출력 전달 | 없음. |
| `scripts/` 타입 검사 | 없음. `scripts/.luaurc` 에 같은 별칭이 있다. |
| 절차 | 최초의 정정 변경 요청. 제도 도입 당일에 제출되었다. |

## 5. 근본 원인 및 시정 조치

| 항목 | 내용 |
|---|---|
| 근본 원인 | 커밋 전에 스테이징된 파일을 검토하지 않았다. |
| 시정 조치 | 매 커밋 전에 `git status` 를 확인하고, 도구가 생성하는 파일은 무시 목록에 둔다. |
