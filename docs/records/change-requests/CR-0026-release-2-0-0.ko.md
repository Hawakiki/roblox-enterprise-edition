# EnterpriseEdition 2.0.0 릴리스

> 본 문서는 CR-0026 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 요약

본 변경 요청은 EnterpriseEdition 2.0.0 을 릴리스한다. Roblox Studio 가 스크립트를 검사하듯 새 Luau 타입 솔버 하나로 검사한 첫 릴리스이다(CR-0025).
생성자는 `any` 캐스트 없이 인스턴스를 반환하며, 코드에는 그런 캐스트가 하나도 남지 않았다.
코드의 계약, 서비스 토큰, 리모트, 저장 기록은 하나도 바뀌지 않았지만, 승인된 문서의 의무를 하나 없애고 다른 하나를 바꾸므로 MAJOR 릴리스이다.

## 2. 배경

1.2.0 이후 CR-0025 가 승인되어 `develop` 에 들어왔다.
CR-0025 는 모든 Luau 파일을 옛 솔버로도 검사하라는 EE-STD-0001 §4 의 의무를 없앤다. 또 EE-STD-0006 §6 의 의무를 바꾸어, 1.2.0 이 요구한 대로 인스턴스를 `any` 로 캐스트하는 생성자를 이제는 보고한다.
두 표준이 2.0.0 으로 올랐으므로, 이 릴리스의 번호는 2.0.0 이다(EE-STD-0008 §4.2).
1.2.0 에 맞춰 클래스를 쓴 템플릿 사용자는 생성자마다 캐스트를 없애야 한다.

`v1.2.0` 이후 계약 모듈, 서비스 토큰 대장, `DataStoreConstants` 는 바뀌지 않았다. `default.project.json` 에는 검사에 쓰는 솔버라는 Workspace 속성 하나가 늘었을 뿐 리모트는 없다.
`v1.2.0` 이후 인용된 다른 변경 요청은 `release/1.2.0` 을 `develop` 에 다시 머지한 커밋이 인용한 CR-0024 뿐이며, 이는 1.2.0 에 속한다(EE-STD-0008 §5.3).

## 3. 범위

- `develop` 에서 딴 `release/2.0.0`(EE-POL-0004 §5)
- push 하지 않는 새 clone 에서의 예행연습: 릴리스를 `main` 에 머지하고 그 머지 커밋에 태그를 달고, 워크플로처럼 태그를 detached 로 체크아웃하여, 모든 검사를 돌리고, 플레이스를 빌드하고, 2.0.0 의 노트를 생성한다.
- 승인 후, 변경 동결이 아닐 때: `release/2.0.0` 을 `--no-ff` 로 `main` 에 머지하고, 그 머지 커밋에 `v2.0.0` 태그를 달고, `release/2.0.0` 을 `develop` 에 다시 머지한다.
- `main`, `develop`, 태그의 push 와 `production` 환경의 배포 승인은 기록상 결재권자에게 맡긴다.
  워크플로가 2.0.0 을 어떻게 배포했는지는 다음 요청이 기록한다.

## 4. 영향도 평가

| 영역 | 영향 |
|---|---|
| `main` | 머지 커밋 하나로 1.2.0 에서 2.0.0 으로 옮겨 간다. |
| 릴리스 | 2.0.0 이 플레이스와 노트와 함께 게시되어 최신 릴리스가 된다. |
| 템플릿 사용자 | 1.2.0 에 맞춰 쓴 클래스는 생성자의 캐스트를 없앤다. 그 밖에 요구되는 것은 없다. |
| 로블록스 코드 | `develop` 그대로이다. 예행연습에서 결함이 나올 때만 릴리스 브랜치가 이를 바꾼다. |
| 문서 분량 | 변경 요청 하나 |

## 5. 원복 계획

`v2.0.0` 의 GitHub 릴리스를 지우고, `main` 과 `develop` 의 머지 커밋을 되돌린다.
태그는 룰셋이 요구하는 대로 남는다. 정정은 2.0.1 로 릴리스한다(EE-STD-0008 §4.6).

본 요청을 시행 완료로 표시하기 전에, push 하지 않는 새 clone 에서 릴리스를 예행연습하였다.
그곳에서 `release/2.0.0` 을 `main` 에 머지하고 그 머지 커밋에 `v2.0.0` 태그를 달았으며, 워크플로처럼 태그를 detached 로 체크아웃하였다. 그 트리는 `release/2.0.0` 의 트리와 같았다.
새 솔버 하나와 새로 내려받은 로블록스 정의로 `tools/check.sh` 가 통과하였고, `rojo build` 가 CR-0025 에서 Roblox Studio 로 확인한 플레이스와 같은 크기인 54841 바이트의 플레이스를 빌드하였다.
2.0.0 의 노트는 CR-0025 와 CR-0026 을 담았고, CR-0024 는 뺐다.
달력은 2026-11-01T02:21:14Z 에 배포를 허용하였다.
예행연습에서 결함이 나오지 않았으므로, 릴리스 브랜치가 바꾸는 것은 이 기록뿐이다.
