# 첫 신입 투입 훈련 지적 사항 정정

> 본 문서는 CR-0006 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 요약

첫 신입 투입 훈련에서 회사 규칙의 결함 여섯 가지가 발견되었다.
본 변경 요청은 이를 정정하고, 그중 하나가 다시 일어나지 않도록 규칙 하나를 추가한다.

## 2. 배경

맥락이 없는 에이전트에게 평범한 과제 하나를 주되, `AGENTS.md` 가 있다는 사실은 알리지 않았다.
에이전트는 스스로 입구를 찾았고, 요청을 `Submitted` 로 제출한 뒤 규칙이 요구하는 대로 결재 지점에서 멈췄다.
그 요청은 머지되지 않았으며 태그 `archive/drill-0001` 에 보존되어 있다.

에이전트는 다음 여섯 가지를 보고했다.

| 번호 | 결함 |
|---|---|
| 1 | 승인된 문서를 개정할 수 없다. 개정은 `In Review` 를 거쳐야 하는데, `In Review` 는 `0.x.y` 버전만 허용했다. |
| 2 | `AGENTS.md` 는 MAJOR 를 "의무에 관한 것"이라고 설명하여 EE-POL-0001 §9 와 어긋났다. |
| 3 | EE-POL-0006 은 에이전트가 서명하지 않는다고 하는데, `AGENTS.md` 는 에이전트에게 서명 줄을 쓰게 한다. |
| 4 | 릴리스 엔지니어링 같은 부서명과 `hotfix` 같은 코드 식별자가 EE-POL-0002 의 용어와 다르게 번역되어 있었다. |
| 5 | 제출 전에 승인된 요청을 어떻게 기록하는지 정한 곳이 없었다. |
| 6 | 변경 요청 CR-0002 부터 CR-0005 까지는 양식이 요구하는 원복 계획 없이 제출되었다. |

## 3. 범위

- EE-POL-0001: 개정은 새 버전으로 검토한다. 기록은 해당 종류 양식의 모든 절을 갖춘다.
- EE-POL-0002: 조직 단위의 이름은 음역할 수 있고, 코드 식별자는 번역하지 아니한다.
- EE-POL-0004: 제출 전에 승인된 요청, 요청을 제출하는 단위, 개정의 결재
- EE-POL-0006: 에이전트는 자신이 일하는 사람을 위해서만, 그 사람의 권한으로 서명 줄을 쓴다.
- EE-TPL-0002: 요청의 시작 상태를 EE-POL-0004 와 일치시킨다.
- 개정된 정책의 모든 하위 문서를 새 개정판 기준으로 재검토하고 인용을 갱신한다.
- checkpatch: `VERSION_STATUS_MISMATCH` 가 검토 중인 개정을 허용하고, 신규 규칙 `TEMPLATE_SECTION_MISSING` 이 양식의 절을 요구한다.
- CR-0002 부터 CR-0005 까지 원복 계획을 소급 추가한다.
- `AGENTS.md`, `CLAUDE.md`, `.gitignore`: 문구 정정, 지뢰 목록 추가, 에이전트 작업 사본 무시

## 4. 영향도 평가

| 영역 | 영향 |
|---|---|
| 출력 전달 | 없음. |
| 검토 중인 문서 | 정책 하나가 바뀌면 하위 문서가 따라야 하므로, 통제 문서 13종이 다시 검토에 들어간다. 위계가 설계대로 작동하는 것이다. |
| 개발 생산성 | 승인된 문서를 다시 개정할 수 있게 된다. |
| 기록 | 시행된 변경 요청 4건이 제출 당시 빠뜨린 절을 갖추게 된다. |

## 5. 원복 계획

본 변경의 머지 커밋을 되돌린다.
그러면 승인된 문서를 다시 개정할 수 없게 되며, 본 변경을 되돌리기 위해 개정해야 할 문서도 예외가 아니다.
