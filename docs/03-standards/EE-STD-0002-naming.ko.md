# 명명 규칙

> 본 문서는 EE-STD-0002 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 목적

본 표준은 로블록스 코드의 모듈, 타입, 멤버 이름을 정하여, 열어 보기 전에 이름만으로 그것이 무엇인지 알 수 있게 한다.

## 2. 적용 범위

1. 본 표준은 `src/` 아래의 모든 모듈에 적용한다.
2. `scripts/` 아래의 도구는 대신 리눅스 커널의 전통을 따른다(EE-STD-0001 §9).
3. 조립 지점인 `init.server.luau` 와 `init.client.luau` 는 Rojo 가 이름을 정하므로 적용을 면제한다.

## 3. 모듈

1. 모듈 이름은 Pascal case 로 쓴다(`MODULE_NAME_SUFFIX`).
2. 계약만 선언하는 모듈은 `ILogger` 처럼 `I` 뒤에 계약 이름을 붙인다.
3. 그 밖의 모든 모듈은 아래 승인된 접미사 중 하나로 끝나며, 접미사가 그 모듈이 무엇인지를 말한다(`MODULE_NAME_SUFFIX`).
   접미사만으로는 이름이 되지 아니한다.
4. 폴더 모듈 `init.luau` 는 그 폴더의 이름을 따른다.

| 접미사 | 다음과 같은 모듈 |
|---|---|
| `Adapter` | 외부의 무언가 위에 계약을 구현한다 |
| `Collection` | 쓰이기 전의 것들을 모은다 |
| `Component` | 사용자 인터페이스의 일부를 그린다 |
| `Constants` | 이름 붙은 값을 담아, 다른 어떤 모듈도 숫자를 담지 않게 한다 |
| `Controller` | 클라이언트의 입력을 처리한다 |
| `Entity` | 식별자를 가진 도메인 객체이다 |
| `Factory` | 객체를 만든다 |
| `Gateway` | 요청을 네트워크 너머로 나른다 |
| `Handler` | 한 종류의 요청이나 이벤트에 응답한다 |
| `Host` | 다른 서비스를 실행하고 멈춘다 |
| `Mapper` | 한 표현을 다른 표현으로 바꾼다 |
| `Options` | 설정을 담는다 |
| `Orchestrator` | 다른 서비스들을 조율한다 |
| `Policy` | 무언가가 허용되는지를 판단한다 |
| `Projection` | 도메인 상태를 다른 곳에 보여 준다 |
| `Provider` | 요청에 따라 인스턴스를 공급한다 |
| `Registry` | 이름으로 무언가를 보관한다 |
| `Repository` | 도메인 객체를 저장하고 꺼낸다 |
| `Scope` | 자원을 소유하고 해제한다 |
| `Service` | 응용 작업을 수행한다 |
| `Specification` | 규칙을 객체로 나타낸다 |
| `Strategy` | 무언가를 하는 여러 교체 가능한 방법 중 하나이다 |
| `Token` | 컨테이너 안에서 서비스의 이름이 된다 |
| `UseCase` | 사용자가 할 수 있는 일 하나를 수행한다 |
| `ValueObject` | 식별자 없는 도메인 값이다 |

## 4. 타입

1. 클래스를 정의하는 모듈은 모듈과 같은 이름의 타입을 내보낸다.
2. 계약 타입은 그 모듈과 같은 이름을 갖는다.

## 5. 멤버

| 멤버 | 형식 | 예 |
|---|---|---|
| 메서드 | Pascal case | `host:Start()` |
| 생성자 | `new` | `ApplicationHost.new` |
| 비공개 필드 | 밑줄로 시작하는 camel case | `_resources` |
| 지역 변수와 매개변수 | camel case | `hostedServices` |
| 모듈 안의 상수 | 대문자 snake case | `MAXIMUM_RETRIES` |

본 절은 강제되지 않으므로 권고이다(EE-CHR-0001 제4조).

|---|---|---|
