# 엔터프라이즈 버전 표기 표준

> 본 문서는 EE-STD-0008 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 목적

본 표준은 EnterpriseEdition 배포판의 번호와 태그 붙이는 방식을 정할 예정이다.

## 2. 상태

본 번호는 확보만 해 둔 것이다.
본 표준은 별도의 변경 요청을 통해 첫 배포와 함께 작성한다.
그때까지 본 문서는 아무 규칙도 정하지 않으며, 본 문서를 근거로 무엇을 하거나 금할 수 없다.
