# Numeric Literal Standard

## 1. Purpose

This standard will set where numeric literals may appear in the Roblox code of the template, which is almost nowhere.

## 2. Status

This number is reserved.
The standard will be drafted together with the template skeleton, through a change request of its own.
Until then it states no rules, and nothing may be done or forbidden under its authority.
