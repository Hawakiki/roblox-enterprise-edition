# 새 타입 솔버 하나로 검사하고, 인스턴스를 캐스트 없이 반환한다

> 본 문서는 ADR-0003 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 배경

ADR-0002 는 인스턴스를 `any` 로 캐스트하여 계약으로 반환하는 ADR-0001 의 생성자를 유지하고, `_implements` 의 각 메서드를 래퍼로 선언하여 두 솔버가 모든 메서드를 시그니처에 대조하게 하였다.
어느 솔버로 코드를 검사할지는 EE-STD-0001 §4 에 맡겼다. 캐스트의 이유로 든 것은 인스턴스를 계약으로 반환하는 것을 거부하는 옛 솔버 하나였다.
로블록스 Studio 는 새 솔버로 스크립트를 검사하며, 저장소의 편집기도 그렇다.

2026-11-01 에 luau-lsp 1.69.0 에서, 옛 솔버가 보고하고 새 솔버가 보고하지 않는 실수는 한 종류였다. 제네릭 함수 본문 안에서 그 타입 매개변수가 얽힌 실수이다.
그런 실수 다섯 가지에 옛 솔버는 오류 다섯 건을, 새 솔버는 0 건을 냈다. 같은 본문에서 매개변수와 무관한 실수, 그리고 제네릭이 아닌 함수의 같은 실수에는 두 솔버가 모두 오류를 냈다.

같은 날 clone 에서 `src/` 의 캐스트 열세 개를 없앴다. 새 솔버는 아무것도 보고하지 않았고, 옛 솔버는 오류 스물일곱 건을 보고하였다.
계약의 메서드 하나가 빠지고, 래퍼가 다른 이름의 메서드를 부르던 클래스는, 생성자가 인스턴스를 캐스트하는 동안 새 솔버를 통과하였고, 캐스트를 없애자 생성자에서 보고되었다.

## 2. 결정

우리는 로블록스 Studio 처럼 모든 Luau 파일을 새 타입 솔버 하나로 검사하고, 플레이스에도 그 솔버를 지정한다.
우리는 각 생성자가 캐스트 없이 인스턴스를 계약으로 반환하게 하며, 새 솔버가 인스턴스에 계약의 모든 메서드가 있는지 대조한다. 로블록스 코드는 `any` 캐스트를 하지 않는다.
우리는 ADR-0002 의 래퍼를 유지한다. 새 솔버는 인스턴스에 메서드가 있는지만 대조하고 그 이상은 보지 않으며, 래퍼가 각 메서드를 시그니처에 대조하기 때문이다.
우리는 제네릭 함수 본문 안에서 타입 매개변수가 얽힌 실수가 보고되지 않음을 받아들인다. `src/` 에는 그런 함수가 일곱 개 있다. `ServiceToken.new`, `ServiceCollection.AddSingleton` 과 `AddTransient`, `ServiceProvider.GetRequiredService`, `ResourceScope.Adopt` 와 `Using`, `ComponentScope.Adopt` 이다.

## 3. 결과

| 구분 | 결과 |
|---|---|
| 긍정 | 로블록스 Studio 가 검사하듯, 솔버 하나로 대상마다 한 번 검사한다. |
| 긍정 | 계약의 메서드가 빠진 클래스는 생성자가 인스턴스를 반환하는 자리에서 보고된다. |
| 긍정 | `src/` 에는 `any` 캐스트가 없으며, 누가 쓰면 checkpatch 가 보고한다(EE-STD-0006 §6). |
| 부정 | 제네릭 함수 일곱 개의 본문에서 타입 매개변수가 얽힌 실수는 보고되지 않는다. 기록상 결재권자가 2026-10-31 에 이 손실을 받아들였다. |
| 부정 | 래퍼는 여전히 계약의 시그니처를 메서드마다 되풀이한다. |
| 중립 | `scripts/tests/AdrFitness.spec.luau` 가 본 기록의 사실을 `rokit.toml` 이 고정한 luau-lsp 에 대조한다. 옛 솔버는 예제가 담아야 할 실수를 담고 있음을 증언하는 데에만 돌린다. |

## 4. 검토한 대안

| 대안 | 채택하지 않은 이유 |
|---|---|
| 옛 솔버를 새 솔버 곁에 남긴다 | 제네릭 함수 일곱 개의 본문은 계속 검사되지만, 모든 대상을 두 번 분석하고, 클래스를 새 솔버에서 가리는 캐스트도 남는다. |
| 새 솔버 하나로 검사하되 캐스트는 남긴다 | 캐스트는 계약의 메서드가 빠진 클래스를 가리며, 캐스트를 요구한 것은 옛 솔버뿐이었다. |
| 래퍼를 없애고 생성자에 맡긴다 | 새 솔버는 인스턴스에 메서드가 있는지만 대조하고 그 이상은 보지 않는다. |
| 새 솔버가 제네릭 함수 본문을 검사할 때까지 기다린다 | 언제 그렇게 될지 알 수 없다. 그렇게 되면 적합도 테스트가 알려 준다. |
