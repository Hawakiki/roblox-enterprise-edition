# 계약의 각 메서드를 래퍼로 선언한다

> 본 문서는 ADR-0002 영문 정본의 번역본이다. 내용이 상충하는 경우 영문 정본이 우선한다.

## 1. 배경

ADR-0001 은 모든 생성자가 자기가 구현하는 계약을 `any` 캐스트로 반환하고, 모든 클래스가 구현하는 메서드를 타입이 그 계약인 `_implements` 테이블에 선언하기로 정하였다. 테이블의 각 항목은 클래스의 메서드를 가리켰다.

luau-lsp 1.69.0 에서 새 타입 솔버는 그런 항목에 대해 메서드가 있는지만 검사하고 그 이상은 보지 않는다. `self: any` 를 받는 계약 메서드에 대해서는 매개변수, 인자, 반환이 어긋나도 보고하지 않는다.
ADR-0001 이 옛 솔버를 남긴 이유는 이것 하나였다. 로블록스 Studio 는 새 솔버로 스크립트를 검사한다.

2026-10-31 에 에이전트 세 명이 옛 솔버를 없앨 수 있는지 논의하여, `type function`, 옛 솔버를 영원히 두는 것, 래퍼를 검토하였다.
`src/` 의 사본에서 `_implements` 의 래퍼는 두 솔버에서 같은 오류를 냈다.
기록상 결재권자는 두 솔버 모두 모든 메서드를 시그니처로 검사하게 된 뒤에 새 솔버 하나만 남기기로 결정하였다.

## 2. 결정

우리는 ADR-0001 의 생성자를 유지한다. 생성자는 `return setmetatable(state, Class) :: any` 로 자기가 구현하는 계약을 반환하며, 로블록스 코드는 그 밖의 `any` 캐스트를 하지 않는다.
우리는 `_implements` 의 각 항목을 계약의 시그니처로 쓴 함수로 작성한다. 그 함수는 클래스의 메서드를 부르고 그 반환값을 그대로 반환한다. 두 솔버 모두 그 호출을 메서드의 시그니처에, 그 함수를 계약의 시그니처에 맞춰 검사한다.
checkpatch 가 `CAST_THROUGH_ANY` 와 `IMPLEMENTS_NOT_WRAPPED` 로 두 부분을 지킨다(EE-STD-0006 §6).
어느 솔버로 코드를 검사할지는 EE-STD-0001 §4 에 맡긴다. 본 결정은 어느 쪽에서도 성립한다.

## 3. 결과

| 구분 | 결과 |
|---|---|
| 긍정 | 매개변수, 인자, 반환이 계약과 어긋난 메서드를 두 솔버가 모두 보고한다. 2026-10-31 에 ADR-0001 아래에서 새 솔버가 하나도 보고하지 않던 어긋남 세 가지는, 래퍼로 감싸자 각 솔버에서 오류 세 건을 냈다. |
| 긍정 | 메서드를 계약에 대조하는 데 더는 옛 솔버가 필요하지 않으므로, 옛 솔버를 없앨 길이 열린다. |
| 긍정 | `any` 캐스트는 클래스마다 한 문장에만 있고, checkpatch 가 그 자리를 찾을 수 있다. |
| 부정 | 클래스마다 한 단계가 늘어난다. 래퍼가 계약의 시그니처를 메서드마다 되풀이한다. |
| 부정 | 래퍼는 실행되지 않는 코드이다. `_implements` 테이블을 부르는 곳은 없다. |
| 부정 | 캐스트는 여전히 생성자를 검사기에서 가린다. 생성자가 무엇을 반환하든 계약으로 통과한다. |
| 중립 | 본 기록 시점에 `src/` 에는 래퍼 서른한 개를 담은 `_implements` 테이블 열다섯 개와, 생성자마다 하나씩인 `any` 캐스트 열세 개가 있다. |
| 중립 | `scripts/tests/AdrFitness.spec.luau` 가 ADR-0001 에 그랬듯 본 기록의 사실을 `rokit.toml` 이 고정한 luau-lsp 에 대조한다(CR-0020). |

## 4. 검토한 대안

| 대안 | 채택하지 않은 이유 |
|---|---|
| 메서드를 가리키는 항목과 옛 솔버를 함께 유지한다 | 로블록스 Studio 는 새 솔버로 검사하는데, 옛 솔버를 이 이유 하나로 남기게 된다. |
| `type function` 으로 구현을 선언한다 | ADR-0001 이 기록한 대로, 옛 솔버가 그 문법을 받아들이지 않고, luau-lsp 1.69.0 에서 공용 모듈이 내보낸 `type function` 은 아무것도 검사하지 않는다. |
| `_implements` 를 없애고 캐스트에 맡긴다 | 캐스트가 클래스를 검사기에서 가리므로, 메서드를 계약에 대조하는 것이 아무것도 남지 않는다. |
| 캐스트 없이 인스턴스를 계약으로 반환한다 | 옛 솔버가 거부하며, 옛 솔버는 아직 코드를 검사한다. |
